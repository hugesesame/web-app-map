# Webアプリの地図 — AIと作る人のための基礎知識

非エンジニアが AIエージェント（Claude Code / Cursor など）と会話しながら Webアプリを作る際に、
躓かず内容を理解し共同制作できるようになるための学習教材です。

- **単一HTMLファイル**（`index.html`）で完結。外部CDN・外部フォント・外部画像への依存はゼロ
- **36トピック** を 入門 / 初級 / 中級 / 上級 の4レベルに配置
- 全トピックが同一フォーマット（ひとことで → たとえ話 → 図解 → AIとの会話例 → つまずきポイント → まとめ）
- 図解は全36点がインラインSVG。OSのダークモードに追従して配色が反転します
- 読了状況は `localStorage` に保存（外部送信なし）

## ローカルで見る

ダブルクリックでブラウザが開きます。ビルド不要です。

```
open index.html
```

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作成（public）
2. `index.html` をアップロード（ドラッグ&ドロップで可）
3. リポジトリの **Settings → Pages** を開く
4. Source を **Deploy from a branch**、ブランチを `main`、フォルダを `/ (root)` に設定して Save
5. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

> ファイル名が `index.html` であることが重要です。別名だとURLの末尾にファイル名が必要になります。

## Vercel で公開する

### GitHub 連携（推奨）

1. 上記の手順でGitHubにリポジトリを用意する
2. [vercel.com](https://vercel.com) にGitHubアカウントでログイン
3. **Add New → Project** から該当リポジトリをインポート
4. **Framework Preset** を **Other** に設定（自動検出に任せるとビルドが失敗することがあります）
5. Build Command と Output Directory は空のまま Deploy

以降、GitHubに push するたび自動で再デプロイされます。

### CLIから直接

```
npx vercel --prod
```

## カスタマイズ

- **配色**: CSS冒頭の `:root` にすべてのデザイントークンが定義されています。`--primary` を変えるとリンク・ボタン・図解のアクセントが一括で変わります
- **ダークモード**: `@media (prefers-color-scheme:dark)` ブロックでトークンを入れ替えているだけなので、構造には影響しません
- **トピックの追加**: `<details class="topic" data-topic="..." data-kw="...">` をコピーして使ってください。`data-kw` は検索用のキーワードです。進捗の分母は各レベルの `トピック完了` の数字を手で更新してください

## 設計方針

デザインは `design.md`（Apple.com のデザインシステム分析）に準拠しています。

- フルブリードタイルの明暗交互（罫線・影を使わず、色の変化そのものが仕切り）
- インタラクティブ要素は単一のアクションブルーのみ
- 影はゼロ、装飾グラデーションもゼロ
- 本文 17px / 行間ゆったり、見出しは負のレタースペーシング

## design.md からの意図的な逸脱

監査の結果、以下2点は仕様どおりにせず、理由を添えて据え置いています。

| 箇所 | design.md | 実装 | 理由 |
|---|---|---|---|
| `--ink-muted-48` | `#7a7a7a` | `#6e6e73` | `#7a7a7a` は白地でコントラスト比 4.30:1 と WCAG AA（4.5:1）未達。キャプション・注釈・用語定義など使用箇所が広いため可読性を優先 |
| テキストリンクの hover | 定義しない | 下線を表示 | 本文中リンクの識別に必要。ナビゲーションの hover は仕様どおり撤去済み |

行間は日本語向けに全体的に広げています（design.md の禁止は「1.47 を下回るな」であり、上げる方向は許容範囲）。
